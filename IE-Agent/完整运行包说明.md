# 完整运行包 v0.3.1（Windows x64）

## 启动

1. 将整个压缩包解压到本地可写目录；建议预留至少2GB空间，不要在压缩软件中直接启动。
2. 进入 agent-platform 文件夹，双击“启动平台.cmd”。
3. 保持命令窗口运行，在浏览器打开 http://127.0.0.1:3100/。
4. 首次账号密码会在本机新生成，打开 var/initial-accounts.json 查看管理员、安全员和司机初始账号，首次登录必须修改密码。

运行包已包含完整源码、预构建界面、Node.js 24 Windows x64、项目依赖、干净业务数据库、解压后的完整历史索引及4份评分重算Parquet。基础平台运行不需要另装Node.js，也不需要npm下载依赖或重新构建。运行期间不要清理node_modules、runtime或var目录。

如果3100端口已被占用，可在命令窗口执行 `set LOCAL_PORT=3102` 后运行启动脚本；浏览器地址也改为对应端口。

## AI与模型重算

AI需要网络和自己的模型密钥，将.env.example复制为.env.local，填写配置后重启。运行包不携带原作者密钥、账号密码或登录状态。

修改模型事件因子、严重度和暴露口径需Python 3.10+（建议3.12），在此目录安装requirements-model.txt中的依赖。仅查看现有数据和基础培训流程无需先安装Python；如果本机Python不可用，涉及Python的因子重算功能需先配置环境。

需重新构建源码时，可自行安装Node.js 24+并运行npm run build；日常使用已打包的dist，不必重新构建。

## 数据与账号

数据为500辆车的2026年6—7月比赛历史数据，不是接入真实车辆的实时数据。公开副本清除了原账号、密码哈希、聊天、学习反馈、私人处置和运行审计，保留评分、课程、标签、历史查询索引和重算输入。

第一次运行会为这台电脑初始化独立账号；以后启动保留本机已创建的账号和业务数据。AI对话完整历史按浏览器和账号保存在本机，清理浏览器站点数据会清除这些历史。

Linux/macOS可使用同包源码和数据，但runtime/node.exe及已打包的原生Node依赖针对Windows x64，需要自行安装对应系统的Node.js 24并执行npm ci。
