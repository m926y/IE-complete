## 下载与启动

1. 解压 IE-Agent-platform-v0.3.1.zip。
2. 下载 IE-Agent-data-v0.3.1.zip，运行 `python scripts/install-data.py --bundle 数据包路径`（或不传--bundle自动下载）。
3. 安装Node.js 24+，执行 `npm ci`、`npm run setup:local`、`npm run build`、`npm run start:local`。
4. 初始账号密码在新电脑的 var/initial-accounts.json 中生成，首次登录须改密。
5. 修改模型因子需要安装 requirements-model.txt；AI密钥由部署者自行配置。

数据包含500辆车的历史评分、事件索引及4份重算Parquet。数据为2026年6—7月历史数据，非真实实时车端数据。

公开数据副本清除账号、密码哈希、登录会话、聊天、私人学习/处置/报告与审计记录，保留评分和课程基线。本机原业务库未修改。
