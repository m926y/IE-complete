# 模型参数表与审核

入口：系统管理 → 规则与运营配置 → 规则草案与审核。

模板附带三条参数说明行，上传时自动忽略；兼容旧版 tau、mu 列名。

1. 下载“当前参数模板（CSV）”，用 Excel 或其他表格工具修改并保存为 UTF-8 CSV。
2. 保留六条“维度”行；权重是 0～1 小数，合计为 1。每行观察窗口和半衰期需一致。
3. 前五个维度可选择 `per_1000km`、`per_100h` 或 `per_active_day`。IMU 使用 `sample_ratio`，维持原始传感器异常比例公式。
4. “事件”行包含已有原始数据支持的事件码、因子名称、所属维度和严重度。可删除某个事件行停用对应因子；不接受未知事件码或重复事件码。
5. τ、μ 和参考尺度属于参考分布参数，改变暴露单位时也应核查其业务意义。参考尺度调整冻结参考风险率，τ/μ 调整小样本平滑。
6. 上传后核对表格，填写草案名称和调整依据，点击“保存并提交审核”。此步骤不会改变当前评分。
7. 填写审核意见，通过审核后点击“正式使用新标准并重算”。仅全车队管理员可操作；安全员和司机无法修改全局模型。

权重页面及手工模型规则编辑的提交，也进入上述审核台账。旧版说明草案作为历史入口保留；正式参数以模型审核台账为准。

正式生效将重算 500 辆车的当前分数、排名、等级、历史评分、扣分台账和复核队列。事件严重度和暴露口径从原始 Parquet 重新计算，不以改文案或等比例缩放替代。事故预测模型与历史原始数据保持独立。

使用历史评分版本的“预览恢复此版本”恢复整个模型，包括当时的权重、事件因子、严重度、暴露口径和参考参数；只点“恢复原始权重”仅改变编辑表单中的权重。恢复生成新的版本，保留所有历史审核和生效记录。
