## 边界和整理原则

两部分各自使用独立环境，不能把算法的 `src`、配置、数据复制进工作台同名目录。工作台中的 `scripts/scoring_source` 是该发行版自带的冻结实现，保留原路径。

保留原有 README_*.md，源代码和测试可能引用这些路径。运行环境、数据库和必要的本地数据保留，避免把完整运行包整理成不能启动的源码包。删除缓存、日志、Python 字节码及可再生成的文档渲染中间件；原始设计文档和交付结果保留。

`.local-backup/` 仅在本地保存替换前旧工作台的差异文件，以及 IE亮剑 原 Git 历史。旧工作台的独有业务状态不合并进 v0.3.1；恢复时先停止服务，再按备份清单恢复。备份不上传，不能将其作为公开发行数据。

IE亮剑 的本地设计草稿和导入试验材料继续保留在自己的目录内并排除上传。迁移目录后如旧虚拟环境无法启动，请在子项目内重建 `.venv`。
